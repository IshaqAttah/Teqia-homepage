DevOps Fundamentals

Linux, containers with Docker, orchestration with Kubernetes, and pipelines that ship code safely. The longest programme we run, ending in a production project you present publicly.

Apply to learn this Fund this program
  • How long24 weeks
  • LevelAdvanced
  • CertificationPortfolio projects
  • Cost to youFree, always

Is this the right start for you?

Every program has a level. Pick the one that matches where you are today, not where you wish you were.

Who this is for

You have already built, coded or configured something yourself, and you want the depth that production work demands.

What you need

Time to study each week, and a laptop if you have one. If you do not have a laptop or steady internet, say so on your application. It will not count against you.

What you will learn

The skills you leave with, and use in the work you build.

  • Linux
  • Git
  • Docker
  • Kubernetes
  • Terraform
  • AWS
  • CI/CD

Curriculum roadmap

Every module is hands on, reviewed by a mentor, and finishes with something you can show.

  1. 1

    1. Orientation & Linux Foundations

    Weeks 1 to 3

    Shell scripting, users and permissions, process management, networking fundamentals and server configuration.

    You finish with: Automated server setup script

  2. 2

    2. Git & Team Collaboration

    Weeks 4 to 6

    Branching strategies, resolving merge conflicts, pull request reviews and pre-commit hooks.

    You finish with: Team repository project

  3. 3

    3. Docker & Containers

    Weeks 7 to 10

    Multi-stage Dockerfiles, image optimisation, container networking, volumes and Docker Compose.

    You finish with: Containerised three-tier application

  4. 4

    4. AWS Cloud Infrastructure & IAM

    Weeks 11 to 14

    VPC and subnet design, EC2 auto scaling, load balancers, least-privilege IAM policies and monitoring.

    You finish with: Highly available web architecture

  5. 5

    5. Kubernetes & Helm

    Weeks 15 to 18

    Pods, deployments, ingress, Helm charts, ConfigMaps, secrets and rolling updates.

    You finish with: Application deployed to a Kubernetes cluster

  6. 6

    6. Terraform & Infrastructure as Code

    Weeks 19 to 21

    Declarative infrastructure, remote state, reusable modules and automated drift detection.

    You finish with: Reusable Terraform stack

  7. 7

    7. Capstone Production Project Final project

    Weeks 22 to 24

    An end to end project with a GitOps pipeline, automated tests, and Prometheus and Grafana monitoring.

    You finish with: Public demo day presentation
